# IEP Monte Patria — versiones oficiales

Canal público de instaladores y actualizaciones de escritorio para Windows.

La aplicación consulta las versiones publicadas aquí. El código fuente está alojado en un repositorio separado y privado. Este repositorio solo distribuye instaladores y metadatos de actualización; no contiene datos de la iglesia ni registros de miembros.

Para instalar o actualizar, descarga `IEP-Monte-Patria-Setup-<version>.exe` desde la sección **Releases**. La aplicación conserva su base de datos local durante las actualizaciones.
